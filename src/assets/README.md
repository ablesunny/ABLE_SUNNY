# Portfolio Assets

Place your assets in this directory according to the following structure:

```text
src/assets/
├── images/
│   ├── profile/
│   │   └── avatar.jpg (Placeholder for your profile image)
│   ├── projects/
│   │   ├── vision-track.jpg
│   │   ├── portfolio.jpg
│   │   ├── ecommerce.jpg
│   │   └── task-manager.jpg
│   └── beyond/
│       ├── mma.jpg
│       └── football.jpg
├── docs/
│   └── Able_Sunny_Resume.pdf
└── README.md
```

**Note:** Until you add the actual files, the code will use generic placeholder elements (like colored divs or SVG icons).
